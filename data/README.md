# Synthetic fixture formats

All files are generated by `python scripts/generate_data.py` and contain fictional
identities and documentation IPv4 addresses. The dataset models a fixed exercise
on 2026-01-15, not real security activity. There are no credentials or payloads.

The loader reads sorted `*.log` files from `nginx/` and sorted `*.jsonl` files from
each other telemetry source. A file is required in each directory, but it may be
empty for a custom scenario. Blank lines and lines beginning with `#` are ignored.
`incidents/` is an output example directory and is never ingested.

Every JSON row requires `synthetic: true`, a timezone-aware `timestamp`, and
`source_ip`. Source-specific fields are:

| Source | Fields / permitted values |
| --- | --- |
| auth | `username`, `resource`, `result`: `failure` or `success` |
| cloud | `principal`, `resource`, `action`: `DownloadObject` or `ListObjects`; nonnegative integer `bytes` |
| firewall | `user`, `destination`, `action`: `allowed` or `denied` |
| application | `user`, `resource`, `action`: `role_change` or `page_view`; role changes require `previous_role` and `new_role`, each `viewer` or `admin` |

User and resource labels permit 1–120 ASCII letters, digits, underscores, periods,
slashes, colons, or hyphens. JSON metadata is allowlisted, not copied wholesale.
An `admin` → `viewer` change is normalized as `role_change`, not escalation.

Nginx lines use this exact educational access-log subset:

```text
IP - USER [DD/Mon/YYYY:HH:MM:SS +0000] "METHOD /path HTTP/1.1" STATUS BYTES
```

`METHOD` is GET or POST, `STATUS` is 100–599, and `BYTES` is a nonnegative integer.
Paths contain word characters, slashes, or hyphens; query strings are unsupported.
The synthetic user field is available because this is a controlled fixture.
Use English abbreviated month names when generating the example log.

The checked-in incident snapshot is derived from the pipeline. It is an initial
pending report and intentionally has no fabricated analyst-review timestamps.
